# Крупные задачи по системам

Задачи MVP выполняются в первые шесть месяцев. Задачи целевого развития планируются на месяцы 7–12.

## Deposit Service

| Код | Горизонт | Задача | Зависит от |
|---|---|---|---|
| DS1 | MVP | Согласовать контракт API и схему CSV. | — |
| DS2 | MVP | Реализовать read-only API общих ставок. | DS1 |
| DS3 | MVP | Реализовать полный CSV-экспорт, расписание, повторную передачу и журнал. | DS1, INF2 |
| DS4 | MVP | Добавить метрики, оповещения, документацию и контрактные тесты. | DS2, DS3 |
| DS5 | 7–12 месяцев | Версионировать форматы и подготовить профили выгрузки для новых партнёров. | результаты MVP |

## Система кол-центра банка

| Код | Горизонт | Задача | Зависит от |
|---|---|---|---|
| CC1 | MVP | Спроектировать простой экран ставок для операторов. | DS1 |
| CC2 | MVP | Подключить API, кэш последней версии и отображение времени обновления. | DS2 |
| CC3 | MVP | Провести приёмочное тестирование и обучить операторов. | CC2 |
| CC4 | 7–12 месяцев | Улучшить доступность интерфейса по обратной связи пожилых клиентов и операторов. | запуск MVP |

## Инфраструктура банка / SFTP

| Код | Горизонт | Задача | Зависит от |
|---|---|---|---|
| INF1 | MVP | Согласовать сетевую схему, ключи, учётные записи и правила хранения файлов. | DS1 |
| INF2 | MVP | Развернуть SFTP-зону и тестовый доступ партнёра. | INF1 |
| INF3 | MVP | Настроить аудит, мониторинг, алерты и резервирование конфигурации. | INF2 |
| INF4 | 7–12 месяцев | Проверить восстановление в резервном ЦОД и автоматизировать сверку доставки. | статистика MVP |

## Партнёрский кол-центр
